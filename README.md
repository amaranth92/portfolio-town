# Portfolio Town — Frontend & Deployment Rhythm

## What this repo means to me
A React + Vite portfolio-style project used to show I can structure front-end build workflows clearly and keep UI delivery repeatable.

## Recruiter-focused notes
- **Case**: Deployment-ready frontend skeleton and task flow
- **Focus**: build reproducibility and project organization
- **Why useful**: useful when a backend developer can also communicate UI-side expectations clearly

## Quick proof points
- Clear npm scripts for build/run/deploy workflow
- Organized asset and script structure
- GitHub Pages ready deployment flow

## Run
```bash
git clone https://github.com/amaranth92/portfolio-town.git
cd portfolio-town
npm install
npm run build
npm run dev
```

## Skills shown
React, TypeScript, Vite, delivery workflow management
