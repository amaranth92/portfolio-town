# Kim Seongkyung Portfolio

Interactive web portfolio for a Java-centered web programmer.

Live site: https://amaranth92.github.io/portfolio-town/

Language routes:
- English: https://amaranth92.github.io/portfolio-town/en
- Korean: https://amaranth92.github.io/portfolio-town/ko

## Profile

Kim Seongkyung is a web programmer based in Seoul with 6 years and 8 months of commercial experience. He majored in Computer Information Engineering at Korea National University of Transportation, worked on projects for LG U+, SK hynix, and the Korea Institute of Drug Safety & Risk Management, and managed/developed systems at CareerCare's IT Research Institute.

## Career Highlights

- InhouseSoft: Korea Institute of Drug Safety & Risk Management project work with Spring Boot, React, PostgreSQL, Excel bulk upload improvement, and document workflow features.
- Ourcom: SK hynix ethics management system backend and multilingual web screens.
- CareerCare: CANDI maintenance, Java migration, BusinessPeople web/app development, MSSQL, AWS deployment, SEO, and PHP homepage maintenance.
- Bogo Information System: LG U+ project shared modules and WebSquare screens.

## Side Projects

- Aussie Pus Studio: public game/app hub for browser and mobile-friendly experiments.
- Photo EXIF Sorter: Python automation for organizing large travel photo archives by date and location metadata.
- Decody: developer utility for parsing and decoding backend debugging strings.

## Tech Stack

Java, Spring Boot, JSP, Servlet, MyBatis, React, JavaScript, jQuery, Ajax, Thymeleaf, WebSquare, MSSQL, Oracle, PostgreSQL, AWS, Jenkins, GitHub, Jira, IntelliJ, Python, Linux, ffmpeg, Selenium.

## Run Locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run typecheck
npm run lint
npm run build
```

## Deploy

The static production build is published through the `gh-pages` branch.

```bash
npm run build
```
