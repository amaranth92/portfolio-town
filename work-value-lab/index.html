근무시간 계산

출근 시간과 퇴근 시간에서 휴게 시간을 빼면 실제 근무 시간이 나옵니다. 같은 9시간 체류라도 점심 60분을 제외하면 실근무는 8시간입니다.

근무시간

야근비 계산

이 계산기는 8시간을 넘는 시간을 야근 후보로 보고 시급의 1.5배를 적용합니다. 회사 규정과 근로계약에 따라 실제 금액은 달라질 수 있습니다.

야근비

회의 비용 계산

회의 비용은 참석자 수, 회의 시간, 시간당 인건비를 곱해 계산합니다. 짧은 회의도 여러 명이 들어가면 하루 예산을 빠르게 씁니다.

회의비

집중블록 계산

하루 목표 집중시간을 블록 단위로 나누면 오늘 필요한 몰입 세션 수가 보입니다. 240분 목표에 50분 블록이면 5블록이 필요합니다.

집중블록

광고와 콘텐츠 원칙

광고는 계산 입력칸을 가리지 않는 별도 영역에만 둡니다. 사용자가 실수로 누르게 만드는 배치 대신, 도구와 설명 콘텐츠를 먼저 제공합니다.

일값 계산소개인정보를 서버로 전송하지 않는 브라우저 계산기입니다.
